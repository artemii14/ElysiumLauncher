## Что уже сделано

### Интерфейс

- Modern: библиотека с поиском, сортировкой и панелью действий справа.
- Legacy: компактный выбор экземпляра Minecraft и кнопки запуска/установки.
- Переключение Modern/Legacy — в настройках. Старые верхняя панель и новостная полоска скрыты.
- Собственная тема Midnight и SVG-значки; стандартные темы Prism сохранены.
- Справа отображаются имя и иконка выбранной сборки; клик по иконке открывает выбор.
- Заголовок окна ровно `Elysium Launcher`, без ветки и версии.
- Внешний вид настраивается в Settings → Appearance: акцент Midnight, выключатель
  анимации и три встроенных процедурных фона (сияние, звёзды, волны).
- «Разрешить перемещение» по умолчанию выключено. Включение + «Применить»
  разблокирует кнопки и заголовки целых блоков. Порядок сохраняется отдельно
  для Modern/Legacy, есть сброс. Значки заголовков: ≡ заблокировано, ↕ разблокировано.
- Исправлен случай, когда фон виден только справа: общая поверхность Modern
  рисует сцену и под пустой библиотекой, viewport и rail используют общие координаты.
  Нативная рамка ОС и поля ввода не превращаются в анимированные элементы.
- Drop блока принимается и поверх дочерних кнопок другого блока.
- Схема порядка кнопок v2: при переходе с v1 старый порядок один раз сбрасывается.

### Установка Minecraft и модов

- Быстрое создание vanilla: выбрать версию → новый экземпляр с автоматическим именем.
- Локальный импорт совместимого LaunchWrapper-профиля OptiFine. OptiFine не раздаётся
  и автоматически не скачивается; Forge и другие неподходящие профили не маскируются под vanilla.
- Sodium-рецепты Fabric и NeoForge для поддерживаемых стабильных версий Minecraft.
  Обязательны Sodium, Iris, LambDynamicLights и zoom (Zoomify в приоритете, иначе Ok Zoomer).
  Fabric API обязателен для Fabric. Sodium Extra и официальный Mod Menu опциональны.
  Не подставлять неофициальный порт Mod Menu для NeoForge без отдельного решения пользователя.
- Перед установкой метаданные обновляются; есть проверка SHA-512, зависимости,
  ограничения размера кэша/ответов и таймауты. Отсутствие обязательного мода исключает рецепт.
- Создаются только НОВЫЕ сборки. **Существующие экземпляры автоматически не обновлять**.
  Альфа/бета-версии модов могут допускаться с маркировкой; Minecraft — stable.
  Совместимость метаданных не является гарантией запуска игры.

### ZeroTier и локализация

- Опциональная панель подключений к отдельно установленному ZeroTier One.
- **Публикация/поиск хостов удалены по просьбе пользователя. Не восстанавливать.**
- При отсутствии ZeroTier показывать объяснение, не обходить разрешения сервиса/токенов.
- Сохранены языковой селектор и каталоги upstream. Добавлен офлайн-слой Elysium:
  английские основные надписи главного экрана, русские новые настройки; часть
  настроек также на немецком, французском, испанском, финском.
- **Локализация неполная**: часть сообщений Sodium, OptiFine, ZeroTier остаётся
  на русском/английском. Динамические панели полностью обновляются после перезапуска.

## Где искать код

- `launcher/ui/MainWindowModes.cpp`: Modern/Legacy, панели действий, vanilla, OptiFine.
- `launcher/ui/MainWindow.cpp`: поиск, пустая библиотека, применение настроек.
- `launcher/ui/widgets/HomeCustomization.{h,cpp}`: фон, таймеры, порядок кнопок/блоков.
- `launcher/ui/widgets/AppearanceWidget.{h,cpp,ui}`: настройки внешнего вида.
- `launcher/ui/instanceview/InstanceView.cpp`: фон непосредственно под списком экземпляров.
- `launcher/ui/themes/ElysiumTheme.h`: палитра Midnight и QSS.
- `launcher/Application.cpp`: регистрация настроек и короткий заголовок окна.
- `launcher/translations/ElysiumTranslator.h`: дополнительный офлайн-перевод.
- `launcher/translations/TranslationsModel.cpp`: upstream-каталоги; они приоритетнее дополнения.
- `launcher/ui/dialogs/SodiumPresetDialog.*`, `launcher/modplatform/modrinth/SodiumPreset.h`:
  каталог и проверка Sodium-рецептов.
- `tests/HomeCustomization_test.cpp`: Qt-регрессии фона, drop, блокировки, сохранения/сброса.
- `scripts/check_elysium.py`: структурные smoke-проверки, НЕ замена компиляции.
- `.github/workflows/windows.yml`, `elysium.yml`: нативные сборки, тесты, упаковка.
- Одноразовый `.github/workflows/publish-preview.yml` выполнил публикацию и удалён,
  чтобы не перезаписывать вручную добавляемые автором файлы релиза.
- `docs/INTERFACE-MODES.md`, `SODIUM-PRESETS.md`, `ZEROTIER.md`, `WINDOWS-GITHUB.md`:
  детали функций и ограничений.

## Следующие проверки / известные ограничения

1. Проверить релиз и наличие обоих бинарных assets, а не только автоматических архивов исходников.
2. В Windows вручную проверить перемещение за ↕ после разблокировки и применения,
   drop на кнопку, восстановление после перезапуска и запрет при блокировке.
3. Проверить все фоны с пустой библиотекой, с экземплярами и при поиске без результатов;
   проверить восстановление анимации после сворачивания и выключение таймера.
4. Продолжить полную локализацию оставшихся диалогов; не называть её завершённой заранее.
5. Проверять реальные установки Sodium в новых экземплярах; старые не трогать.
6. Пользователь спрашивал про Inno Setup: объяснена упаковка всей чистой portable-папки,
   исключение `portable.txt`, per-user установка, ярлыки с
   `--dir "%APPDATA%\\ElysiumLauncher"`. В релиз автор отдельно загрузил `ElysiumLauncher-Windows.exe`; его установка здесь не проверялась.
   Не удалять пользовательские миры/аккаунты при деинсталляции.

## Ограничения окружения предыдущего чата

Локального Qt SDK не было: нативная проверка шла в GitHub Actions.
Прямое скачивание Actions-артефактов в Arena обрывалось на Azure Blob (EOF),
поэтому для публикации используется runner GitHub, который скачивает artifacts
и загружает их в Release. Прямые rerun/dispatch Actions ранее получали 403;
push в рабочую ветку запускал workflows. Права могут изменяться — проверять,
но не запрашивать пароли/токены в чате. При проблемах аутентификации просить
переподключить GitHub в Arena, не придумывать успешный результат.
