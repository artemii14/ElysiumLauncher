# Elysium Midnight icons

Original GPL-3.0-only vector UI artwork. Generated by
`scripts/generate_midnight_icons.py` (edit its paths, then regenerate).

- 24 × 24 grid, 1.7-unit rounded strokes, transparent backgrounds.
- Lavender #b7a8ff; mint, rose and amber for success, error and warning.
- Used by navigation, actions, menus, settings pages and component editors.
- Qt handles disabled icon rendering and scales SVGs for high-DPI displays.
- External service logos and user-selected instance artwork intentionally retain
  their identity through the upstream `multimc` fallback. They are not UI glyphs.

New installations default to Midnight. Existing Elysium installations using the
old default `pe_colored` are migrated once; explicitly selected other icon packs
are preserved. Midnight can also be selected in the icon theme settings.
