# Elysium Hyprland-inspired icons

GPL-3.0-only. A variant of our own Midnight vector artwork, with thinner cyan
strokes, semantic status colors and terminal/tiling-inspired glyphs.
No Hyprland logo, external icon artwork, fonts or compositor dependencies.
Regenerate with `python3 scripts/generate_hyprland_icons.py`.

Select **Elysium Hyprland** under Settings → Appearance → Icons; independently
select the **Elysium • Hyprland** application theme for the complete look.
Uncovered service logos/instance artwork use the existing multimc fallback.
The pack does not change the user's chosen default automatically.
