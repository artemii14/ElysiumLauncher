# Два режима ElysiumLauncher

Это собственная реализация на Qt поверх существующего Elysium/Prism, а не запуск трёх лаунчеров внутри одного. Режимы используют одни сборки, аккаунты, Java, настройки и механизм запуска.

## Modern — библиотека

Верхняя кнопка **«Библиотека · Modern»** включает рабочее пространство с боковой навигацией в духе XMCL:

- существующая библиотека с группами, поиском и сортировкой;
- создание сборки, импорт модпака, Forge/Fabric через стандартный мастер;
- быстрые переходы к модам и компонентам выбранной сборки;
- быстрые vanilla и импорт OptiFine доступны и здесь;
- сохранены стандартные функции Elysium: логи, экспорт, Java, управление мирами и ресурсами через окно сборки.

Это не точная копия XMCL и не перенос его Vue/Electron-фронтенда. Рассмотрены `HomeLayout.vue` и структура боковой навигации XMCL; исходный код и графические ресурсы XMCL не перенесены.

## Classic — быстрый запуск

Кнопка **«Быстрый запуск · Classic»** открывает компактный экран в духе сценария Legacy:

1. Выбрать существующую сборку из списка.
2. Нажать **«Играть»**. Проверка аккаунта, Java и загрузка игры выполняются обычным механизмом Elysium.
3. При необходимости открыть настройки сборки, остановить игру или сменить аккаунт.

Поиск библиотеки не скрывает сборки в компактном списке. `Ctrl+K` возвращает в Modern и фокусирует поиск. Выбор режима сохраняется в `ElysiumInterfaceMode`; при возврате восстанавливается видимость стандартных панелей.

## Автоматическое создание vanilla

**«+ Vanilla автоматически»** открывает существующий каталог версий Minecraft. После выбора:

- имя задаётся как `Vanilla <версия>`;
- группа — `Elysium Vanilla`;
- применяется обычная задача установки Elysium с её загрузками, прогрессом, отменой и обработкой ошибок;
- если уже есть сборка с таким именем и группой, той же версией и только стандартными Minecraft/LWJGL-компонентами, она выбирается вместо создания новой;
- игра не запускается без дополнительного нажатия **«Играть»**.

Имя и группу повторно вводить не нужно. Доступность каталога и загрузок зависит от сети и унаследованных metadata-сервисов. Это не режим обхода авторизации.

## OptiFine: локальный импорт

OptiFine не распространяется с лаунчером, не скачивается с зеркал и не устанавливается путём скрытого исполнения JAR.

Поддерживается профиль **LaunchWrapper**, созданный официальным установщиком OptiFine, с библиотеками `optifine:OptiFine` и `optifine:launchwrapper-of` либо `net.minecraft:launchwrapper`.

1. В отдельной `.minecraft` установить нужные Minecraft и OptiFine официальным установщиком. Elysium не выполняет этот шаг за пользователя.
2. В Elysium создать/выбрать vanilla **той же версии Minecraft**, без Forge/Fabric/NeoForge и без уже установленного OptiFine. Остановить игру.
3. Нажать **«Импорт OptiFine…»** и прочитать предупреждение.
4. Выбрать `.minecraft/versions/<OptiFine>/<OptiFine>.json`.
5. Выбрать каталог `.minecraft/libraries`, в котором находятся JAR из этого профиля.
6. Elysium проверит профиль и наличие JAR, скопирует библиотеки в локальную папку выбранной сборки и добавит компонент OptiFine с нужным tweaker.

Проверяются соответствие `inheritsFrom`, тип профиля, разрешённые Maven-координаты, дубли и выход путей за пределы выбранного каталога. URL, произвольные main class, JVM-аргументы и пути из исходного JSON не переносятся. Отличающиеся существующие JAR не перезаписываются. Это проверка структуры импорта, **не антивирусная проверка**: локальные JAR будут исполняться при запуске Minecraft и должны происходить из доверенного источника.

Для Forge можно установить совместимый OptiFine вручную через существующий раздел модов. Автоматической установки OptiFine на Fabric/NeoForge, загрузки OptiFabric, патчинга любого установщика или поддержки всех исторических форматов в этой реализации нет.

## Происхождение

- Основа и игровой backend: Elysium → ElyPrism/Prism, существующие уведомления и GPL сохранены.
- XMCL: <https://github.com/voxelum/x-minecraft-launcher>, MIT; используется как ориентир организации рабочего пространства, код не скопирован.
- Legacy archive: <https://github.com/LegacyLauncher/archive>, файл лицензии сообщает All rights reserved. Используется как ориентир компактного сценария, код/ресурсы не скопированы. Пользователь сообщил о частном разрешении, но его условия не представлены и в публичный репозиторий ARR-материалы не добавлены.

Исходники новых режимов публикуются в текущей рабочей ветке, отдельно от main. Предыдущий Windows-архив не содержит новые режимы; предупреждение Chrome по тому архиву не устраняется изменением интерфейса. Новые сборки также не имеют цифровой подписи и не считаются антивирусно проверенными.

## Проверка

Структурные проверки: `python3 scripts/check_elysium.py`.

Qt-тесты преобразования и ограничений импорта добавлены в `tests/OptiFineProfile_test.cpp`. После сборки: `ctest --test-dir build -R 'OptiFineProfile|InstanceSearch' --output-on-failure`.

Для этой итерации пока не выполнены полная native-сборка, визуальный тест режимов и запуск реальной игры с импортированным OptiFine. В текущей среде нет Qt SDK/ECM. Статус новой сборки и её архивы смотри в GitHub Actions для соответствующего коммита; файлы от более старых коммитов новые режимы не содержат.

Ручные сценарии: пустая библиотека; переключение режима после поиска; перезапуск в Classic с возвратом в Modern; создание/повторное создание vanilla; удаление выбранной сборки; старт/остановка игры; несовпадающая версия OptiFine; отсутствующий JAR; конфликт существующих библиотек; отмена каждого диалога.

## Настройка главного экрана

Настройки → Внешний вид → Главный экран:

- **Анимированный фон** — мягкие движущиеся световые пятна на правой панели Modern
  и фоне Legacy. Отключается независимо от темы; при скрытом/неактивном окне таймер
  останавливается. Частота ограничена 20 кадрами/с.
- **Цвет акцента** — выбор цвета для темы Midnight и фонового свечения. Другие темы
  сохраняют собственные палитры. Чтобы вернуть исходный акцент, выберите `#a997ff`.
- **Разрешить перемещение** — по умолчанию выключено. При включении перетащите
  кнопку на другую в той же панели/строке. Кнопки временно работают как элементы
  раскладки, а не запускают команды. После настройки выключите переключатель.
  Порядок Modern/Legacy хранится отдельно, не зависит от языка или размеров окна.
- **Сбросить порядок кнопок** — сброс обоих режимов после применения настроек.

Изменения применяются кнопкой применения/сохранения настроек. Отмена не записывает
новый цвет, переключатели или сброс. Само перетаскивание сохраняется сразу.

### Переводы

Существующий выбор языка и загрузка каталогов Prism сохранены. Добавлен встроенный
офлайн-слой для основных исторически русскоязычных надписей главного экрана
(английский fallback), а также русские, немецкие, французские, испанские и финские
названия новых настроек. Полный upstream-каталог имеет приоритет над этим слоем.
Это **не полный перевод всех диалогов Elysium**: отдельные сообщения Sodium,
OptiFine и ZeroTier пока остаются на русском, подсказки могут оставаться на
английском. После изменения языка перезапустите лаунчер, чтобы обновились и
создаваемые вручную панели. Дополнительные языки используют существующие каталоги
и английский fallback для основных надписей Elysium.

### Блоки и готовые фоны

Переключатель «Разрешить перемещение» теперь разблокирует и заголовки блоков
(метка ⠿). Перетащите заголовок на другой блок: вместе с ним переместятся все
кнопки. В Modern это «Библиотека», «Выбранная сборка», «Лаунчер», в Legacy —
соответствующие три группы действий. Внутри блоков можно менять порядок кнопок
отдельно. Порядок блоков сохраняется отдельно для каждого режима по стабильным
идентификаторам; сброс в настройках возвращает и блоки, и кнопки.

В настройках доступен выбор трёх встроенных процедурных анимаций: **Северное
сияние**, **Звёздное небо**, **Волны**. Скачивание файлов и установка кодеков не
нужны. Выбор сохраняется после применения настроек. Фон теперь рисуется также
непосредственно в области библиотеки Modern перед отрисовкой сборок: непрозрачный
viewport больше не скрывает его. Повышена видимость свечения; восстановление
таймера после сворачивания обрабатывается отдельно. Выключение анимации возвращает
статический фон. Импорт видео/GIF не добавлен.

Раскладка отдельных кнопок переведена на схему v2: после обновления старый порядок
кнопок сбросится один раз, чтобы перестановка блоков не меняла идентичность кнопок.

### Исправления пустой библиотеки и drop-зон

Главная поверхность Modern теперь сама рисует фон, в том числе за сообщением
пустой библиотеки. Библиотека и правая панель рисуют части одной сцены с общими
координатами, вместо отдельных несвязанных анимаций. Нативная рамка окна и поля
ввода остаются обычными элементами интерфейса.

Drop целого блока принимается и поверх дочерних кнопок целевого блока, не только
на узком заголовке. В выключенном состоянии заголовок показывает ≡ и подсказку о
разблокировке в настройках; во включённом — ↕. За заголовок можно переместить весь
блок; раскладка по-прежнему блокируется переключателем в настройках.

Добавлены Qt-тесты: запрет drop при блокировке, drop на дочернюю кнопку,
отклонение данных другого окна, восстановление/сброс порядка, фон под пустым
QLabel и отрисовка слева/справа с возможностью выключения. Они выполняются в CI
с платформой offscreen; это не замена ручной проверке native drag-and-drop Windows.


## Тема в стиле Hyprland

В Настройки → Внешний вид выберите тему приложения **Elysium • Hyprland**,
а в списке значков — **Elysium Hyprland**. Это два независимых выбора:
можно сочетать тему с другими значками. Настройки пользователя не переключаются
автоматически. Основные цвета: графитовый фон, cyan/teal-фокус, голубые подписи;
скруглённые панели с тонкой рамкой и контрастные выделения списков.

Это самостоятельная Qt-тема, вдохновлённая tiling/rice-оформлением, а не официальный
проект Hyprland. Работает и на Windows, Hyprland/Wayland не нужны. Системный blur,
прозрачные окна и анимации композитора не имитируются. 71 SVG-иконка основана на
собственных glyphs Midnight; настройки/запуск/панели имеют отдельную геометрию.
Сервисные логотипы и иконки экземпляров не заменяются. Акцентный picker Midnight
по-прежнему управляет Midnight/фоном, у новой темы собственная фиксированная палитра.

Вместе с темой исправлены потенциальный null-dereference кнопки установки Sodium
при частично заполненной строке каталога, состояние кнопки после удаления строк
и перевод динамических настроек фона при смене языка.


### Дополнительные анимированные фоны

В Настройки → Внешний вид → Главный экран добавлены «Неоновый дождь»,
«Орбиты» и «Неоновая сетка». Теперь доступно шесть процедурных пресетов.
Используют выбранный цвет фонового акцента, общий холст Modern/Legacy,
существующие 20 FPS и остановку таймера в скрытом/неактивном окне. Новые фоны
не требуют скачивания видео или установки кодеков. Старый выбор сохраняется.


### Общие параметры Minecraft

Настройки → Minecraft → Настройки игры: семь прокручиваемых вкладок — графика,
звук (все стандартные категории), управление мышью, чат и интерфейс, доступность,
назначения основных клавиш и внешний вид модели. Более 100 параметров, включая
слоты панели, язык игры и эффекты камеры. Есть сброс к базовым значениям с
подтверждением; сохранение — обычной кнопкой настроек лаунчера.

Общие параметры по умолчанию отключены. При включении они записываются перед
каждым запуском; модовые конфиги, resourcePacks и маркер версии не перезаписываются.
Первый исходный options.txt сохраняется в options.txt.before-elysium.
Отключение синхронизации не восстанавливает исходный файл автоматически.
Некоторые параметры зависят от версии Minecraft и могут игнорироваться старой
или новой игрой; это не редактор всех настроек сторонних модов.

Для файла используются значения Minecraft: FOV нормализуется относительно 70°,
чувствительность 100% соответствует 0.5, громкость 35% — 0.35. Все значения
проверяются по общей схеме, повреждённые значения ограничиваются допустимым
диапазоном. Отсутствующие boolean-параметры теперь получают правильные исходные
значения, а не безусловное false. Настройки разделены прокруткой, чтобы не
растягивать окно за границы экрана.


### Исправление применения и русского интерфейса

Изменение любого общего игрового параметра теперь автоматически включает его
применение; простое открытие настроек ничего не включает. Переключатель можно
явно выключить после редактирования. Нажмите «Применить»/«ОК» и перезапустите игру:
уже запущенный Minecraft не перечитывает options.txt на лету.
Тип мягкого освещения записывается с учётом версии (число до 1.19.3,
boolean начиная с 1.19.3); для 1.14–1.15 используется fancyGraphics.

Русский каталог встроен в приложение: даже без доступа к серверу переводов
русский язык присутствует в списке и основные страницы не переключаются на
английский из-за отсутствующего index_v2.json. ru_RU нормализуется в ru.
Выбранный пользователем другой язык принудительно не меняется.


### Hyprland: плиточная компоновка и цвет иконок

Тема обновлена по референсу: графитово-фиолетовые поверхности, тонкие лиловые
рамки, отдельные карточки библиотеки и правой панели, компактная строка рабочей
области. «Играть» выделено акцентом; по умолчанию действия выбранной сборки идут
первыми. Сохранённый пользователем порядок блоков не меняется.
Это нативный интерфейс Qt, без обещания размытия/прозрачности настоящего композитора.

Настройки → Внешний вид → Сбросить цвета возвращает акцент #a997ff после
«Применить». Порядок блоков, анимация, тема и пользовательские иконки не сбрасываются.
Встроенные наборы Midnight/Hyprland теперь перекрашиваются вместе с акцентом;
красные ошибки, жёлтые предупреждения и зелёные статусы сохраняют смысловые цвета.
Внешние наборы и картинки сборок не перекрашиваются. Смена цвета не требует
перезапуска. При переходе между Midnight и Hyprland их родные наборы переключаются
вместе с темой; сторонний выбранный набор сохраняется.
