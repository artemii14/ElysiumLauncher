# Собрать Windows-версию через GitHub

На свой компьютер не нужно устанавливать Qt, MSYS2 или компилятор. Они устанавливаются на временный Windows-сервер GitHub Actions.

## 1. Опубликовать текущие изменения

Нужен весь проект из текущей рабочей ветки, а не только YAML-файл. Пока изменения находятся только в Arena, GitHub не сможет собрать их.

После commit/push текущей ветки `arena/66b41468-ubiquitous-happiness` файл `.github/workflows/windows.yml` должен быть виден в этой ветке на GitHub. Не загружайте каталоги сборки, секреты или токены. Если переносите исходники вручную архивом, учитывайте, что libnbtplusplus — Git submodule: простой ZIP может не содержать его исходники.

## 2. Дождаться Actions

1. Открыть репозиторий на GitHub → **Actions**.
2. При необходимости разрешить выполнение workflows.
3. Найти **ElysiumLauncher Windows** и запуск для нужной ветки/коммита. Push автоматически запускает сборку; по умолчанию ни PR, ни merge для этого не требуется.
4. Дождаться зелёного статуса. Первый запуск скачивает зависимости и может занять заметное время.
5. Открыть завершённый запуск → **Artifacts** → **ElysiumLauncher-Windows-x64-portable**.

Для ручного запуска: **Actions → ElysiumLauncher Windows → Run workflow → выбрать ветку → Run workflow**. GitHub показывает кнопку ручного запуска, когда workflow с `workflow_dispatch` уже есть в default branch. Если файл есть только в рабочей ветке, используйте автоматический запуск по push. Если workflow был отключён при первом push, включите его и повторите push с новым коммитом.

Скачивание artifact через веб-интерфейс может потребовать входа в GitHub. Artifact хранится 14 дней, это не постоянный релиз в разделе Releases.

## 3. Запустить

- Распаковать ZIP целиком, например в `C:\Games\ElysiumLauncher`.
- Запустить `elysiumlauncher.exe` из распакованной папки, не из ZIP.
- Не удалять DLL, `platforms`, `jars`, `qt.conf`, `portable.txt` и другие файлы архива. Это portable-пакет, а не один независимый EXE.
- Папка должна быть доступна на запись: portable-версия хранит данные рядом с собой. Не используйте `Program Files`.
- Java для Minecraft выбирается/устанавливается отдельно через функции лаунчера; игровой runtime не входит в portable-архив.

Сборка не подписана цифровым сертификатом. Windows может показать предупреждение о неизвестном издателе. Проверяйте источник файла; не отключайте антивирус и не игнорируйте детектирование угроз.

## Если сборка упала

Открыть красный запуск → **Windows x64 portable** → первый красный шаг. Скопировать последние строки ошибки из Configure / Build / Test / Package. При ошибке artifact не публикуется намеренно, чтобы не выдавать неполный архив за готовый продукт.

Workflow добавлен, но ещё не выполнен на GitHub в этой сессии. Успешная сборка и тесты не заменяют ручную проверку входа в аккаунт и запуска Minecraft на чистой Windows.
