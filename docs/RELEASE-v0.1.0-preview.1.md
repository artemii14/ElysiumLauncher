# Elysium Launcher 0.1.0 Preview 1

Тестовый релиз независимого форка ElyPrismLauncher / Prism Launcher на C++ и Qt 6.
Это не стабильный подписанный выпуск. Minecraft и OptiFine в комплект не входят.

## Скачать

- **Windows x64:** `ElysiumLauncher-Windows-x64-portable.zip` — распакуйте целиком
  в доступную для записи папку и запустите `elysiumlauncher.exe`. Это portable,
  не установщик Setup.exe. Не распаковывайте поверх единственной копии своих миров без бэкапа.
- **Linux x64:** `ElysiumLauncher-Linux-x86_64.AppImage` — Ubuntu 24.04 / glibc 2.39+
  или совместимая система. Разрешите исполнение: `chmod +x ElysiumLauncher-Linux-x86_64.AppImage`.
- **SHA256SUMS.txt:** контрольные суммы обоих файлов. Сумма проверяет целостность,
  но не заменяет подпись издателя и не является антивирусной гарантией.

## Возможности

- Modern и Legacy, тема Midnight, SVG-значки, библиотека с поиском и сортировкой.
- Выбор акцента и встроенных анимированных фонов: сияние, звёздное небо, волны.
- Перестановка кнопок и целых блоков с сохранением порядка. Включите
  «Разрешить перемещение» в настройках внешнего вида и нажмите «Применить»;
  блоки перемещаются за заголовок ↕.
- Фон под пустой библиотекой и при показе сборок; общая сцена для обеих частей Modern.
- Быстрое создание vanilla, локальный импорт совместимого профиля OptiFine.
- Новые Sodium-сборки Fabric/NeoForge по проверяемым рецептам; существующие сборки не обновляются.
- Панель подключений к отдельно установленному ZeroTier One, без публикации/поиска хостов.
