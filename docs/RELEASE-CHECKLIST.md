# Перед релизом ElysiumLauncher

## Авторизация и сервисы

- Зарегистрировать собственное приложение Microsoft Identity Platform и проверить device-code flow, наличие Minecraft и безопасное хранение/обновление токенов. Передавать свой `Launcher_MSA_CLIENT_ID` при конфигурации CMake.
- Зарегистрировать собственный клиент Ely.by, проверить допустимые redirect URI и задать `Launcher_ELY_CLIENT_ID` и `Launcher_LOGIN_CALLBACK_URL`. Текущие значения унаследованы; это не новые регистрации Elysium.
- Получить разрешённый ключ CurseForge (`Launcher_CURSEFORGE_API_KEY`) и проверить условия использования; если ключа нет, не обещать работающую интеграцию. Для Imgur аналогично нужен собственный `Launcher_IMGUR_CLIENT_ID`.
- Проверить `Launcher_META_URL`, `Launcher_LEGACY_FMLLIBS_BASE_URL`: сейчас используются унаследованные сервисы PineconeMC. Не подменять их без совместимых метаданных, но согласовать использование или развернуть свои.
- Перед релизом заменить/отключить унаследованные новостные URL, callback и прочие сторонние URL, где это требуется. Updater Elysium по умолчанию отключён намеренно.
- Не записывать пароли и токены в Git, issue, скриншоты или логи CI.

## Ручной smoke-test

- Первый запуск с чистым каталогом данных: тема Midnight, выбор языка, мастер Java и аккаунтов.
- Проверить другой встроенный стиль и пользовательскую тему, масштабирование 100/150/200%, клавиатурный фокус, маленькое окно.
- Создать vanilla-сборку, Fabric-сборку и импортировать `.mrpack`; проверить запуск, остановку, повторный запуск, лог ошибки.
- Вход через Ely.by и Microsoft, отмена входа, выход, просроченный токен, отсутствие сети.
- Поиск: имя, часть имени, группа, кириллица, `[`, `.*`, пробелы, пустой результат, очистка Escape, Ctrl+K.
- Проверить счётчики при добавлении/удалении сборок с активным фильтром и без него.
- Сортировка по имени/времени/последнему запуску, сохранение после перезапуска.
- Пустая библиотека: создание сборки доступно; поиск без совпадений не удаляет данные.
- Удаление/восстановление, копирование, экспорт и импорт; обновление модов и модпаков.
- Проверить отдельные каталоги настроек Elysium и ElyPrism, не мигрировать данные без бэкапа.

## Дистрибуция

- Успешные Release-сборки и CTest на Linux, Windows и macOS, не только development CI.
- Полноценное тестирование упаковки Qt, Java downloader, иконок и ассоциаций файлов на чистой ОС.
- Подпись, хеш-суммы, политика обновлений и публикация соответствующих исходников GPL.
- macOS `.icon` и `.icns`, Windows `.ico` и manifest требуют отдельного визуального теста. Исходные упаковочные скрипты и nix-файлы ещё содержат имена upstream и не являются готовым релизным pipeline Elysium.
- Перевести новые `tr()`-строки в используемую систему локализации: существующие переводы покрывают унаследованные экраны, но не новые строки Elysium.
