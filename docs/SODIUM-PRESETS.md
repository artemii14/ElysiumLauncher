# Sodium presets

Кнопка «Установить Sodium…» в библиотеке и «Sodium-сборка…» в Legacy создаёт
**отдельный новый экземпляр** в группе Elysium Sodium. Каталог запрашивается
с Modrinth при каждом открытии и по кнопке обновления. Ничего не обновляется
в фоне или в ранее установленных экземплярах.

## Правила

- Стабильные версии Minecraft начиная с 1.14, включая новую нумерацию 26.x.
- Отдельные варианты Fabric и NeoForge, без смешивания загрузчиков.
- Обязательны Sodium, Iris, LambDynamicLights и Zoomify; Ok Zoomer заменяет
  Zoomify, если подходящего полного набора с Zoomify нет.
- Fabric API обязателен для Fabric.
- Sodium Extra и Mod Menu необязательны. Добавляются лишь при разрешимых
  зависимостях без изменения уже подобранного обязательного набора.
- Версии модов рассматриваются от новых к старым по date_published; допускаются
  release/beta/alpha. Перед установкой виден список файлов и каналов.

Варианты с Sodium, но без остальных обязательных модов показываются с причиной
недоступности (в том числе NeoForge), а установка для них отключена. Перед установкой
проверяются required-зависимости Modrinth, закреплённые version_id и incompatible
с ограниченным перебором вариантов. Неразрешимый набор не устанавливается.
Загрузчик берётся из метаданных лаунчера: последний для соответствующего Minecraft,
для Fabric допускается общий список версий loader.

## Скачивание

Генерируется новый modrinth.index.json без удалённого managed ID. Штатный импортёр
скачивает JAR с cdn.modrinth.com и проверяет SHA-512. Имя JAR, домен, HTTPS,
совпадения имён и хеши проверяются до запуска установки. JAR также скачиваются для проверки метаданных при подготовке; файлы не перепаковываются и не публикуются в репозитории.
Список файлов/хешей сохраняется штатным импортёром в mrpack внутри экземпляра.
Generated manifest принудительно отключает ветку обновления существующих сборок.

## Ограничения

Проверка Modrinth не является полноценным решателем всех ограничений из
fabric.mod.json / neoforge.mods.toml каждого JAR: не все авторы переносят туда
все ограничения. Не обещается проверка запуска каждого набора. Требования к
конкретной версии loader и Java также могут уточняться самими модами при запуске.
При несовместимости следует сохранить диагностический лог и скорректировать рецепт.
Сетевые ошибки не трактуются как отсутствие необязательного мода: операция
останавливается с возможностью повторить. Отмена до установки не создаёт экземпляр.

## Проверки

SodiumPreset_test проверяет фильтр Minecraft/loader, безопасные JAR/URL, откат
на старую версию при pinned-зависимости, отсутствующие зависимости и исключение
конфликтующего необязательного мода. scripts/audit_sodium_catalog.py проверяет
доступность файлов по тем же обязательным/необязательным правилам, но не заменяет
resolver и запуск игры.

Ручная проверка: Fabric и NeoForge, скачивание с SHA-512, отмена каталога и
установки, недоступный Modrinth, отсутствующий zoom, beta/alpha в подтверждении,
два экземпляра одной версии без изменения первого, первый запуск и загрузка мира.

При подготовке установки метаданные Modrinth перечитываются заново, даже если
окно каталога было открыто давно. Ответы в рамках одного подбора кешируются
по slug и ID проекта без повторного скачивания одинаковых списков. Общий
объём кеша ограничен 96 МиБ. У сетевых запросов и загрузки метаданных loader
есть тайм-аут 30 секунд; загрузку loader можно отменить из окна прогресса.
Столбец «Мод на зум» показывает читабельные названия Zoomify / Ok Zoomer и
обновляется, если при проверке зависимостей потребовался запасной вариант.


## Исправление конфликта Sodium / Iris (26.2 и 26.3)

Подбор по API Modrinth дополнен чтением **самих JAR** до подтверждения установки:
проверяется SHA-512, затем без распаковки на диск читается `fabric.mod.json`
или `META-INF/neoforge.mods.toml` / `META-INF/mods.toml`. Учитываются `depends` /
`breaks` Fabric и required/incompatible + versionRange NeoForge между присутствующими
модами, Minecraft и выбранным загрузчиком. Правила из API недостаточны: они могут
не содержать запрет Sodium на старый Iris, показанный загрузчиком Fabric.

Resolver теперь откатывает конфликтующую комбинацию и сначала предпочитает новый Iris,
после чего подбирает совместимый Sodium. Если нового совместимого набора нет,
возможна более старая совместимая версия — её точный номер показывается до установки.
Не следует обещать одновременно «всегда самый последний мод» и совместимость.
Нет решения — нет установки, а не заведомо конфликтующий набор.

Ограничения: не реализован полный алгоритм загрузчиков, обход вложенных JAR и поиск
необъявленных в Modrinth отсутствующих проектов. Неподдерживаемый диапазон между
присутствующими модами блокирует подготовку. Для NeoForge не подставляются Fabric-моды
или неофициальные альтернативы обязательных проектов: если LambDynamicLights, Iris
или zoom не опубликован под выбранный MC/loader, строка показывает недостающий мод.
Подготовка требует дополнительного трафика: до 64 MiB на JAR, 256 MiB суммарно,
96 проверяемых версий; XML/JSON/TOML не исполняются. Нет гарантий игрового запуска
без реального тестирования экземпляра. Уже созданные сборки не изменяются.
