# Elysium Launcher 1.1

Последние проверенные CI-сборки из коммита `eaa465a7406ef51429d20b6026e546a6cf144083`.
Бинарники не подписаны. Minecraft и OptiFine в комплект не входят.

## Скачать

- **Windows x64 · portable:** `ElysiumLauncher-1.1-Windows-x64-portable.zip`.
  Распакуйте весь архив в доступную для записи папку и запустите `elysiumlauncher.exe`.
  Это не установщик. Не заменяйте единственную копию своих миров без резервного копирования.
- **Linux x64:** `ElysiumLauncher-1.1-Linux-x86_64.AppImage`.
  Требуется Ubuntu 24.04 / glibc 2.39 или совместимая более новая система.
  Разрешите исполнение: `chmod +x ElysiumLauncher-1.1-Linux-x86_64.AppImage`.
- **SHA256SUMS.txt:** SHA-256 обоих архивов/файлов. Это проверка целостности,
  не цифровая подпись издателя и не антивирусная гарантия.

Установщика EXE для 1.1 в этом релизе нет. Установщик из 1.0 не обновляется
автоматически и не является сборкой 1.1. Уже скачанные файлы также сами не обновятся.

## Что изменилось по сравнению с 1.0

### Новая тема и иконки

- Тема **Elysium • Hyprland**: графитовые панели, тонкие бирюзовые рамки,
  голубые акценты и скругления.
- Отдельный пакет **Elysium Hyprland** из 71 SVG-иконки с тонкими cyan-линиями
  и terminal/tiling-мотивами. Собственное оформление, не официальный проект Hyprland.
- Выбираются независимо в **Настройки → Внешний вид**. Midnight и существующие
  настройки сохранены; Hyprland/Wayland не требуются, системного blur нет.

### Sodium-рецепты и совместимость

- **LambDynamicLights удалён** из состава новых рецептов и проверок доступности.
  Основной набор: Sodium + Iris + Zoomify либо Ok Zoomer; Fabric API обязателен
  для Fabric. Sodium Extra и официальный Mod Menu добавляются при совместимости.
- Проверяются SHA-512 и ограничения внутри JAR: Fabric `depends`/`breaks`,
  NeoForge TOML `versionRange` и required/incompatible зависимости между
  присутствующими модами. Подбор откатывает несовместимые комбинации.
- Приоритет свежего Iris, затем совместимого Sodium; перед установкой
  видны точные номера модов. Более старый совместимый мод может быть выбран
  вместо нового конфликтующего — «всегда последний» не гарантируется.
- Исправлена обработка Fabric-диапазонов вроде `>=26.2- <26.3-`, которые
  могли ошибочно блокировать подготовку корректных наборов.
- Для NeoForge показываются причины недоступности обязательных модов,
  а не молча скрываются строки или подставляются Fabric-файлы.
- Сетевые ошибки показывают конкретные host/path, HTTP-код и причину.

### Исправления интерфейса

- Защита от обращения к отсутствующей ячейке при выборе частично заполненной
  строки каталога Sodium.
- Кнопка установки корректно обновляется при очистке таблицы и изменении доступности.
- Динамические настройки фона обновляют перевод при смене языка.

## Проверка и ограничения

Обе платформы успешно прошли компиляцию, CTest и проверку упакованного запуска:

- [Windows CI](https://github.com/artemii14/ElysiumLauncher/actions/runs/43885411853)
- [Linux CI и AppImage](https://github.com/artemii14/ElysiumLauncher/actions/runs/43885411902)

Добавлены тесты конфликта Sodium/Iris для MC 26.2/26.3, диапазонов Fabric,
метаданных NeoForge, палитры/иконок и состояния таблицы. Структурных smoke-проверок — 19.
Успешные тесты не означают ручную проверку всех ОС, авторизации и игрового запуска
каждого набора. Это не полный resolver загрузчиков: нет обхода вложенных JAR и
проверки всех Java-ограничений. Переводы частичные.

**Уже установленные экземпляры автоматически не изменяются.** Чтобы проверить
исправление рецепта, запустите новую версию лаунчера и создайте новый Sodium-экземпляр.
Сохраните резервные копии миров; при ошибке приложите лог без токенов и личных данных.
