# Виртуальная локальная сеть (ZeroTier One)

Откройте «Эмулятор локальной сети» справа в Modern или через меню «Лаунчер»
в Legacy. Наличие ZeroTier необязательно: кнопка остаётся доступной без него.

## Что осталось

- Подключение по 16-символьному Network ID с подтверждением.
- Статус службы, список сетей и назначенные IP-адреса.
- Копирование IP без маски подсети. При нескольких адресах появляется выбор.
- Отключение от выбранной сети с подтверждением.
- Обновление каждые 15 секунд, только пока окно открыто, и вручную.
- Сохранение выбранной сети при обновлении списка.

**Публикация хоста, поиск участников, имена участников, ввод игрового порта и
собственный UDP-протокол полностью удалены.** Лаунчер не открывает UDP-порт
обнаружения, не рассылает broadcast/multicast и не публикует адреса в фоне.
Самостоятельно установленная служба ZeroTier продолжает работать как обычно.

## Установка и права

Кнопка «Установить ZeroTier…» после подтверждения открывает официальный сайт
в браузере. Лаунчер не скачивает и не запускает установщик сам, не повышает
права и не устанавливает драйверы. Можно отказаться и продолжить пользоваться
лаунчером. На Linux следуйте официальной инструкции для своего дистрибутива.

Для управления нужен доступ к локальному `authtoken.secret`. По умолчанию:
- Windows: `%ProgramData%/ZeroTier/One/authtoken.secret`;
- Linux: `/var/lib/zerotier-one/authtoken.secret`;
- macOS: `/Library/Application Support/ZeroTier/One/authtoken.secret`.

Если файл недоступен, GUI объясняет проблему и позволяет выбрать файл доступа.
Путь выбора действует только до закрытия окна. Лаунчер не копирует токен и не
меняет права файла. Не делайте его общедоступным и не запускайте Minecraft или
весь лаунчер с правами root/администратора ради этой функции. Автоматический
privileged helper не реализован: установка службы ещё не гарантирует доступ к API.

## Совместная игра

1. Создайте сеть через ZeroTier Central (кнопка открывает веб-панель).
2. Все игроки подключаются к одной сети; владелец разрешает доступ в Central.
3. Откройте Minecraft-мир для сети, скопируйте свой ZT IP и сообщите друзьям
   адрес `IP:порт`. Порт показывает Minecraft при открытии мира для сети.
4. Друзья используют «Прямое подключение» в Minecraft.

Обнаружение LAN-мира не гарантируется. Брандмауэр должен разрешать игровой порт;
лаунчер не меняет его правила и не отключает его.

## Безопасность и проверки

API фиксирован: `127.0.0.1:9993`, без прокси и перенаправлений, тайм-аут 5 секунд,
ограничение ответа 1 МиБ. Токен не пишется в настройки/логи и не передаётся Central.
При ошибке API или файла доступа устаревшие сети и адреса очищаются.
Присоединение запрещает default/global routes и DNS, разрешая управляемые
адреса/локальные маршруты: используйте только доверенные сети.

Нативные UI-тесты проверяют ввод Network ID, начальное состояние и отсутствие
удалённых элементов. Структурные тесты проверяют границы локального API и удаление
старого кода. Это не заменяет проверку реальной службы и игры двух участников.
Ручной чек-лист: остановленная служба, неверный токен, недоступный токен, пустой
список, несколько IPv4/IPv6, сохранение выбора, отказ от отключения, закрытие
окна во время запроса, игра двух участников.
