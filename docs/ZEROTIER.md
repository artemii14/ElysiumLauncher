# Виртуальная локальная сеть (ZeroTier One)

Откройте «Эмулятор локальной сети» справа в Modern или через меню «Лаунчер»
в Legacy. Наличие ZeroTier необязательно: кнопка остаётся доступной без него.

## Установка и права

Кнопка «Установить ZeroTier…» после подтверждения открывает официальный сайт
в браузере. Лаунчер **не скачивает и не запускает установщик сам**, не повышает
права и не устанавливает драйверы. Можно отказаться и продолжить пользоваться
лаунчером. На Linux следуйте официальной инструкции для своего дистрибутива.

Для управления нужен доступ к локальному `authtoken.secret`. По умолчанию:
- Windows: `%ProgramData%/ZeroTier/One/authtoken.secret`;
- Linux: `/var/lib/zerotier-one/authtoken.secret`;
- macOS: `/Library/Application Support/ZeroTier/One/authtoken.secret`.

Если файл недоступен, GUI объясняет проблему и позволяет выбрать файл доступа.
Путь выбора действует только до закрытия окна. Лаунчер не копирует токен и не
меняет права файла. Не делайте его общедоступным и не запускайте Minecraft или
весь лаунчер с правами root/администратора ради этой функции. Настройка
ограниченного доступа к службе зависит от ОС; автоматический privileged helper
в этой версии не реализован. Поэтому наличие установленной службы само по себе
ещё не гарантирует возможность управления из GUI.

## Подключение

1. Создайте сеть через ZeroTier Central (отдельная кнопка открывает веб-панель).
2. Введите 16-символьный Network ID, подтвердите подключение.
3. Владелец закрытой сети разрешает участника в Central.
4. Нажмите «Обновить», выберите сеть, скопируйте её IP.
5. Откройте Minecraft-мир для сети. Друзья подключаются к `IP:порт` через
   прямое подключение. Порт показывает Minecraft; LAN-обнаружение не гарантируется.

Окно показывает сети, адреса и статусы, позволяет выйти с подтверждением.
Статусы обновляются вручную. Участники доверенной сети должны разрешить игровой
порт в своём брандмауэре. Лаунчер не меняет брандмауэр и не отключает его.

## Границы безопасности и проверки

Локальный API фиксирован: `127.0.0.1:9993`, без прокси и перенаправлений,
с тайм-аутом 5 секунд. Токен не пишется в настройки/логи и не передаётся Central.
Подключение запрещает default/global routes и DNS, но разрешает управляемые
адреса/локальные маршруты: присоединяйтесь только к доверенным сетям.

Структурные тесты не заменяют проверку на реальных Windows/Linux с ZeroTier.
Ручной чек-лист: отсутствующая/остановленная служба, отказ от установки,
недоступный/ошибочный токен, неверный ID, разрешённая и запрещённая сеть,
копирование IP, выход, закрытие окна во время запроса, игра двух участников.

## Имя и «Стать хостом»

После успешного запроса подключения появляется ввод имени (1–48 символов).
Это имя ElysiumLauncher, **не имя устройства в ZeroTier Central**. Оно сохраняется
локально; кнопка «Изменить имя…» позволяет изменить его или задать позднее.
Отмена ввода не отключает уже присоединённую сеть, но без имени стать хостом нельзя.

Выберите сеть и нажмите «Стать хостом…». IPv4 выбранной сети подставляется
автоматически; принимать можно только адрес, реально назначенный этому компьютеру
в выбранной сети. Укажите порт, который Minecraft показал после «Открыть для сети»,
и подтвердите публикацию. Остальные пользователи открывают окно ZeroTier в
ElysiumLauncher, выбирают ту же сеть и видят имя и `IP:порт` с копированием.
На первом этапе поддерживаются IPv4-сети с префиксами /1–/30, не IPv6-only.

Объявления передаются каждые 3 секунды по UDP 46931 через широковещательный
адрес **только выбранного интерфейса ZeroTier**. Нужны разрешённые broadcasts
в ZeroTier и правила брандмауэра для UDP 46931 у участников. Без них обнаружение
не гарантируется; ручное копирование своего IP из таблицы сетей остаётся доступно.
Это не автоматическое LAN-обнаружение внутри Minecraft и не проброс порта.

«Перестать быть хостом» отправляет отзыв объявления. При потере пакета запись
исчезает примерно через 12–15 секунд. Публикация продолжается после закрытия
окна, пока работает лаунчер; завершается по кнопке, при выходе из сети через
GUI или закрытии лаунчера. Сети обновляются каждые 15 секунд, пока окно открыто;
после внешнего изменения сети при закрытом окне следует открыть GUI и обновить.

Имена объявлений **не удостоверяют личность**: участники одной сети могут
подделывать объявления. Нельзя автоматически запускать команды/подключаться по
таким объявлениям: доступно лишь копирование адреса. IP берётся из адреса
отправителя UDP, не из поля пакета; данные ограничены по размеру и времени жизни.

Дополнительные ручные тесты: два устройства в одной разрешённой сети, имя после
присоединения, отказ от публикации, порт 1/65535, попытка указать чужой IP,
остановка хоста, потеря связи и истечение записи, две разные сети, запрет
broadcast/UDP и закрытие окна во время публикации.
